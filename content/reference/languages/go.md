# Go

## Environment

Qualified supports [Go 1.24](https://golang.org/doc/go1.24), [Go 1.20](https://golang.org/doc/go1.20) and [Go 1.12](https://golang.org/doc/go1.12).

Go versions older than 1.20 are [deprecated](/creating-content/challenges/upgrading-language-versions/#deprecation-process). Use Go 1.24.

## Timeout

The sandbox environment will timeout the code within 12 seconds.

## Packages

The following packages are available:

### Go 1.24

- `github.com/onsi/ginkgo`: `v1.16.5`
- `github.com/onsi/gomega`: `v1.17.0`

### Go 1.20

- `github.com/onsi/ginkgo`: `v1.16.5`
- `github.com/onsi/gomega`: `v1.17.0`

Our Go environment supports the following testing frameworks:
